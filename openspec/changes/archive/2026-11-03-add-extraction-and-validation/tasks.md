## Workflow follow-up

- Create a feature branch before the first commit (for example `feat/extraction-add-extraction-and-validation`); do not commit on `main`.
- Archive with `/opsx:archive`, then commit in atomic commits (dependencies, data model, normalization and grounding, extraction job, validation, API, docs, archive). Push only when asked; open the PR into `main`.
